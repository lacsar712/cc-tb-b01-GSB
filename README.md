# 茶叶拼配审评台

一批拼配采用联评合成：审评员甲先在联评台提交香气、滋味、汤色三项分，生成待合成草稿并得到草稿号；审评员乙在另一会话登录联评台，引用同一草稿号交齐自己的三项分。服务端按两人同项均值（四舍五入保留一位小数）写入正式行，并按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。任一侧缺席则不成行；草稿号不存在则交齐失败。观察员看不到联评入口。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录，顶栏进入联评台，提交批次「春芽」三项分，生成草稿（如 D-0001），总表行数不变。
2. 另一会话以 taster2 登录联评台，引用 D-0001 交齐三项分；总表新增一行，香气/滋味/汤色为两人均值（一位小数）。
3. taster2 引用不存在的草稿号（如 D-9999）交齐，返回失败提示，总表行数不变。
4. observer 登录后顶栏无联评台，直接访问 /joint 返回 403；总表仍可见春茶-A 通过、夏茶-C 不通过。
