# 茶叶拼配审评台

联评合成：审评员甲先在联评台提交香气、滋味、汤色三项分，得到一张待合成草稿（带草稿号）；另一会话的审评员乙引用同一草稿号交齐自己的三项分。服务端把两人的三项分分别取均值、四舍五入保留一位小数，写入审评总表的正式行，再按 0.3 / 0.5 / 0.2 加权出分，7 分及以上通过。任一侧缺席则不成行。

这是制茶审评，不是菜谱，也不是饮食记录。


## 验收

1. taster 登录后顶栏有「联评台」，专页展示待合成草稿与已合成结果；observer 登录后没有联评入口，直接访问 /joint 返回 403。
2. 甲在联评台提交「春芽」三项分后，总表行数不变，草稿出现在待合成列表。
3. 乙在另一会话引用该草稿号交齐三项分，总表多一行，且三项为两人均值（四舍五入一位小数）。
4. 乙引用不存在的草稿号交齐会失败，总表行数不变。
